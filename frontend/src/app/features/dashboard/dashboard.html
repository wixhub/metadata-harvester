Ecological Metadata Harvester Dashboard

🧪 Sandbox Mode

Welcome! This portal allows researchers to ingest, validate and manage ecological metadata (such as Movebank XML and Darwin Core Archives) designed for institutional DSpace repository integration.

💡

What can you do here?

Use + New Ingestion Job to upload new metadata schemas or telemetry files. The system automatically validates formats against biological standards, extracts records, and archives them. Check your recent activity below or explore stored items in the repository.

🔗 Useful links: Movebank Standard Darwin Core (DwC) DSpace Repository
