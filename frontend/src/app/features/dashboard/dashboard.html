🧪 Sandbox Mode

Welcome! This portal allows researchers to ingest, validate and manage ecological metadata - such as Movebank XML and Darwin Core Archives - designed for institutional DSpace repository integration.

💡

How to validate your metadata

Step-by-step guide:

  1. Click + New Ingestion Job in the top right corner.
  2. Upload your ecological metadata file (Movebank XML, DwC-A zip, etc.). The format can be auto-detected!
  3. The Java backend on Render instantly parses and validates your file. If there's an error, you will see it immediately on a red alert banner before finalizing.
  4. Once valid, check the live status in the table below: PROCESSED means ready for DSpace.

Note: Currently running in Sandbox Mode. Need custom DSpace OAuth/REST integration for your institution?
